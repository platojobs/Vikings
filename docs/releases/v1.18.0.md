# v1.18.0 发布说明

- 发布日期：2026-11-05
- 提交：本提交（附注标签 `v1.18.0` 指向该提交）
- 标签：`v1.18.0`
- 对应交付项：`docs/delivery-readiness.md` 的 **P0-1（生产部署入口：无 Dockerfile、无反代/HTTPS、一键脚本仅支持 macOS）**

## 版本定位

一句话：**一台干净的机器拿到仓库，执行 2 步就能起一套能对外服务的完整栈**
（PostgreSQL + Mosquitto + 网关 + Web 后台 + HTTPS 反代），并已在本机真实起栈验证。

本轮只补部署面，不改业务功能、REST 契约与 MQTT 报文格式：

- gateway / web 各自 Dockerfile（多阶段、非 root、健康检查）；
- 独立生产编排 `infra/docker-compose.prod.yml`（与开发编排用途分离）；
- nginx 反代：HTTPS、安全头、`/api` 透传、`/mqtt` WebSocket 升级、可选登录限流；
- 生产 env 模板与一键脚本 `scripts/prod_up.sh`；
- 部署/运维文档与 CI 镜像构建作业。

## 只读核对结论（改动前 → 改动后）

| 项 | 改动前 | 本轮结论 |
| --- | --- | --- |
| 容器化 | 仅 `infra/docker-compose.yml` 起 postgres/mosquitto，注释要求自行补 Dockerfile | `gateway/Dockerfile` + `web/Dockerfile`，`docker build` 真实通过 |
| 生产编排 | 无 | `infra/docker-compose.prod.yml`：5 服务、健康检查、依赖顺序、重启策略、卷持久化 |
| 网络隔离 | 开发编排直接暴露 5432/1883/9001 | 只发布反代 80/443 与设备 1883；gateway/web/9001 仅容器网络；postgres 在 `internal` 网络 |
| HTTPS | 全为 `http://127.0.0.1:*` | nginx 443 + 自签证书验证；文档给出 ACME/正式证书替换步骤 |
| 安全头 | 无 | HSTS、`X-Content-Type-Options`、`X-Frame-Options`、`Referrer-Policy`、`Permissions-Policy`、CSP |
| 登录限流 | 仅网关进程内 IP+账号锁定 | 反代层可选 `limit_req`（默认不启用，附开启方法） |
| 密钥管理 | 开发 `.env` 手填，DB 口令随仓库 | 生产 `.env.example` 全量模板；`prod_up.sh` 首次自动生成随机值；私密路径全部 gitignored |
| 启动路径 | `start_all.sh` 绑定 `/opt/homebrew` 与 macOS | `prod_up.sh` 只依赖 docker/compose/openssl/python3，Linux/macOS 通用 |
| Web/移动端地址 | 开发写死本机地址 | 生产同源 `/api` 与 `wss://<host>/mqtt`；移动端支持带路径的完整 ws(s) URL |
| 文档 | 只有 macOS 开发路径 | 新增 `docs/deployment.md` 与 `docs/operations.md`，README 顶部指向 |

## 新增结构

```text
gateway/Dockerfile              # python:3.12-slim 多阶段，uid 10001 非 root，HEALTHCHECK
web/Dockerfile                  # node:20 构建 → nginx-unprivileged 静态托管，监听 8080
infra/docker-compose.prod.yml   # 生产编排（name: iot-prod）
infra/prod/.env.example         # 生产环境变量模板（标注必改与生成方式）
infra/prod/mosquitto/           # 生产 Broker 配置（绝对路径版）
infra/prod/nginx/               # conf.d / snippets / certs / acme
infra/nginx/web.conf            # web 容器内 nginx 配置（SPA 回退）
scripts/prod_up.sh              # 一键：生成密钥 → 初始化凭证 → 自签证书 → 起栈 → 等健康
scripts/gen_self_signed_cert.sh # 自签证书（SAN 含域名/localhost/127.0.0.1）
.dockerignore                   # 构建上下文裁剪，排除密钥/证书/node_modules/dist
```

## 对外端点

| 端点 | 说明 |
| --- | --- |
| `https://<host>/` | Web 管理后台（SPA） |
| `https://<host>/api/*` | REST，透传 `Authorization`、`X-Forwarded-*` |
| `https://<host>/api/auth/mqtt-credentials` | 登录后换取 Web/移动端只读 MQTT 凭证 |
| `wss://<host>/mqtt` | MQTT over WebSocket（反代 → Broker 9001） |
| `http://<host>/` | 301 跳 HTTPS；`/.well-known/acme-challenge/` 供 ACME |
| `<host>:1883` | 设备 MQTT（TCP，强制账号口令 + ACL） |

内部服务（gateway 8000、web 8080、broker 9001、postgres 5432）均不发布到宿主机。

## 生产环境变量（新增/关键项）

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `APP_ENV` | compose 固定 `production` | 触发启动 fail-fast 校验 |
| `PUBLIC_ORIGIN` | `https://localhost` | CORS 白名单与自签证书 CN |
| `JWT_SECRET` | 脚本生成 | `openssl rand -hex 48`，≥32 字符 |
| `POSTGRES_PASSWORD` | 脚本生成 | `openssl rand -hex 24`，同时拼进 `DATABASE_URL` |
| `ADMIN_PASSWORD` | 脚本生成 | 生产拒绝弱口令 |
| `MQTT_PASSWORD` / `MQTT_WEB_PASSWORD` / `MQTT_MOBILE_PASSWORD` | 脚本生成 | Broker 服务/客户端身份 |
| `MQTT_PASSWORD_FILE` | `/run/secrets/mosquitto.passwd` | 网关签发设备凭证时写入 |
| `MQTT_PASSWORD_FILE_MODE` | `644` | 网关与 Broker 容器不同 uid 共享同一文件 |
| `DEPLOY_UID` / `DEPLOY_GID` | 脚本取 `id -u/id -g` | 网关容器以该非 root 用户运行 |
| `HTTP_PORT` / `HTTPS_PORT` / `MQTT_PORT` | 80/443/1883 | 低端口受限时本地验证用 8080/8443 |

`SEED_DEMO_USERS` 固定 `false`；`LOGIN_*` 沿用 v1.16.0 的网关内锁定。

## 兼容与迁移

- **开发路径不变**：`scripts/start_all.sh` 仍是 macOS 本地开发入口；生产用 `prod_up.sh`。
- **已有裸机部署**：改为容器部署时需把现有 PostgreSQL 数据导入新卷，并重新初始化
  `infra/prod/secrets/mosquitto.passwd`、给存量设备重签凭证（用户名=deviceId）。
- **Web/移动端**：生产构建 `VITE_API_BASE=""` + `VITE_MQTT_WS="/mqtt"`，运行时按同源推导；
  移动端网关地址填 `https://<host>` 时实时链路自动用 `wss://<host>/mqtt`。
- **REST 契约**：路径与字段不变；反代只增加安全头与 429（可选限流）语义，见
  `docs/contracts.md` 1.2。

## 偏差与运维影响

1. **自签证书是验证边界**：HTTPS、代理语义、安全头均已验证，但不证明公网信任链；
   上线必须替换正式证书（`docs/deployment.md` 4.2）。
2. **反代层限流默认关闭**：`limit_req` 规则与 snippet 已提供，需要时在
   `/api/auth/login` 的 location 引入；默认仍由网关内 IP+账号锁定兜底。
3. **API 轮换凭证后 Broker 需重载**：网关容器无法向另一容器发 SIGHUP，
   接口返回 `reloaded=false`；按 `docs/operations.md` 执行
   `docker compose ... restart mosquitto`。
4. **单实例网关**：登录限流与 MQTT 消费为进程内，多副本需外部组件（P1-1/P2-4）。
5. **数据库迁移仍是 `create_all` + 幂等 init.sql**：升级前必须备份（P1-3）。
6. **CI 只构建镜像不起栈**：真实起栈在本地验收完成；CI 新增 `images` 作业防止
   Dockerfile 悄悄坏掉，同时不与 e2e 作业抢端口。
