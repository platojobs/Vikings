# v1.27.0 · 移动端概览首页

> 发布日期：2026-11-05
> 定位：把 App 从「工具集合」变成「产品」——打开第一眼是运营概览，而不是调试用的设备模拟器。

## 版本定位

- **默认入口换成概览**：`HomeShell` 第 0 页由设备模拟器改为「概览」；设备模拟器**没有删除**，
  迁到第 4 个 tab「工具」，仍可完整使用。
- **数字全部来自真实接口**：概览不维护第二套统计，直接消费既有 `GET /api/stats/overview`
  （v1.27.0 在同一响应上追加聚合字段），与 Web 仪表盘同一口径。
- **数据不足就说不足**：近 24 小时趋势按真实小时桶绘制，空桶是真实 0；
  数据不满 24 小时显示「数据不足 24 小时」，不补假点、不画平滑假曲线。
- **不新增常驻连接**：实时事件与连接状态复用告警中心已有的那一条前台订阅，
  概览只做监听；切 tab / 切后台即停监听与轮询。

## Tab 结构调整与理由

| 位置 | v1.26.0 | v1.27.0 | 理由 |
| --- | --- | --- | --- |
| 0 | 设备模拟器 | **概览（默认）** | 客户打开 App 第一眼应看到业务态势；调试工具不应占据首屏 |
| 1 | 移动看板 | 移动看板（不变） | 看板是日常操作主路径，位置与行为不变 |
| 2 | 告警中心 | 告警中心（不变） | 角标、前台订阅、批量确认全部保持原行为 |
| 3 | — | **工具（设备模拟器）** | 保留设备模拟器全部能力，只是从首屏降级为工具入口 |

把模拟器放在最后而不是塞进看板：模拟器属于「联调/演示」场景，与看板的数据浏览语义不同；
放在第 4 个 tab 仍是一级可达入口（不需要多级菜单），只是不再抢默认入口。

## 概览展示内容与口径

| 区块 | 内容 | 数据来源 |
| --- | --- | --- |
| KPI | 设备总数、在线率（在线/离线）、未签发凭证数、未处理告警数 | `device_total` / `device_online` / `device_offline` / `device_credential_missing` / `alert_open` |
| 告警分布 | warning / critical 两个级别条 | `alert_warning_open` / `alert_critical_open`（与 v1.21.0 收窄后的口径一致，之和 = `alert_open`） |
| 趋势 | 近 24 个整点小时桶的双柱（上报量 / 新增告警） | `trend`；`trend_complete=false` 时显示「数据不足 24 小时」 |
| 异常设备 | 有未处理告警或离线的设备，最多 10 台 | `abnormal_devices`（`reason` = `alert` / `offline` / `alert+offline`） |
| 顶部状态条 | 实时连接 / 已切换轮询（每 15 秒） | 告警中心转发的 `RealtimeState` + 轮询标记 |

异常设备可打开只读详情（`GET /api/records/latest`，展示温度/湿度/电压/电量/信号），
并可「在移动看板查看该设备」：切到看板并把设备 ID 写入搜索框（`focusSeq` 支持重复点击）。

## 图表实现与代价

选择 **`CustomPainter` 手绘双柱**，不引入第三方图表库：

- 依赖代价为零：`pubspec.yaml` 未新增依赖，APK/AAB 体积与首屏无变化；
- 概览只需要 24 个桶的柱状对比，不需要缩放/图例/工具箱，ECharts 类库属于过度设计；
- 绘制在 `paint` 内完成，不建额外组件树，Widget 测试可直接断言 key 与文案。

## 实时与省电

- **只有一条连接**：告警中心在前台始终维护唯一的 MQTT 订阅。概览**不创建** MQTT 客户端，
  由 `HomeShell` 用 broadcast `Stream<RealtimeEvent>` + `ValueNotifier<RealtimeState>` 转发。
- **状态一致**：告警中心在开始/停止订阅、进入/退出轮询时通过 `onRealtimeState` 回调上报，
  概览与角标读同一份状态，不存在「概览显示实时、告警中心显示轮询」的分裂。
- **可见性**：概览只在 `active（当前 tab）&& 前台 && 已登录` 时监听，并按 `feedPolling` 启停
  15 秒轮询；切走或切后台立即取消订阅与定时器。
- **到达即更新**：`ReportEvent` / `AlertEvent` 做乐观自增，800ms 后拉一次 REST 快照校正；
  `StatusEvent` / `GroupChangedEvent` 只触发刷新。
- **登录态**：未登录直接展示登录页；401 清会话并回登录页，提示「登录已失效，请重新登录」。

## 权限

概览是纯只读页面，viewer / operator / admin 看到的内容完全一致；不提供确认告警、轮换凭证、
下发指令等写操作入口，因此没有「按钮禁用」这类半可用状态。
