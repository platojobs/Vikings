# v1.25.0 · P2-3 规模化上限 + P2-5 CI 体验

> 发布日期：2026-11-05
> 需求：P2-3（设备筛选远程搜索、批量确认自动分批）、P2-5（CI concurrency、失败日志 artifact）

## 版本定位

v1.25.0 是交付就绪审计的收尾版本，关闭 P0/P1/P2 全部清单中的最后两项：

- 移动端告警中心不再受「设备 200 台 / 批量 100 条」的页面级上限约束；
- CI 同一分支的新推送自动取消旧运行，失败时保留可下载的关键日志。

本版本**无数据库迁移**，网关接口与既有客户端兼容（仅移动端页面行为变化）。

## 设备筛选：从「一次拉 200 台」改为远程搜索

| 项 | 行为 |
| --- | --- |
| 数据来源 | `GET /api/devices?keyword=<输入>&page=1&pageSize=20`，复用网关既有 `keyword`（`device_id` / `name` 的 ilike 片段匹配，大小写不敏感） |
| 防抖 | 输入停止 **300ms** 后才发请求；连续输入只保留最后一次结果（`_deviceSearchSeq` 丢弃过期响应） |
| 下拉展示 | 面板最多 4 条匹配项（名称 + ID + 在线状态），点击即应用为 `deviceId` 筛选并刷新告警列表 |
| 截断提示 | 面板底部固定展示「共 N 台匹配，仅显示前 M 台；继续输入以缩小范围」；`total` 来自接口返回，**不静默截断** |
| 清除 | 输入框清除按钮与「设备」Chip 的删除按钮都会回到全部设备 |
| 名称缓存 | 仅为告警行展示设备名，首屏轻量取 20 台；未命中时行内回退显示设备 ID，不再用于筛选候选 |

网关单页上限为 200，本实现取前 20 台并用 `total` 提示剩余量；若后续需要「滚动加载更多设备」，
可再增加分页加载，不影响当前契约。

## 批量确认：超过 100 条自动串行分批

新增 `device_app/lib/services/bulk_ack_runner.dart`：

| 项 | 行为 |
| --- | --- |
| 分批 | 服务端单次上限 100 条，客户端按 100 条切分（150 条 → 100 + 50） |
| 并发度 | **严格串行**：第 N 批完成（成功或失败）后才发第 N+1 批，避免瞬时压力 |
| 结果合并 | `acked` / `already_acked` / `not_found` 逐批累加；成功后仅移除 `acked` 行并同步总数/未读数 |
| 单批失败 | 记录批次序号、该批 ID 与错误；**不回滚已成功批次**，摘要展示「第 X 批共 N 条提交失败（原因），失败批次未计入已确认，已成功部分保留」 |
| 失败重试 | 失败批次的 ID 保持选中，可直接再次确认；成功/已确认/不存在项不再选中 |
| 401 | 中止后续批次，`unsubmitted` 如实计数，页面清会话回登录页，摘要附带已成功部分 |
| 403 | 展示本轮禁用写操作并保留失败选中项，不把失败算作成功 |

## CI 体验

- 工作流级 `concurrency`：
  - `group: CI-${github.ref}`；
  - `cancel-in-progress: github.ref_type != 'tag'`——同分支/PR 新推送取消旧运行，标签构建不取消。
- 失败日志 artifact（仅 `if: failure()` 上传，保留 **7 天**）：
  - `gateway-test-log-<run_id>`：`gateway/pytest.log`；
  - `flutter-test-logs-<run_id>`：`flutter-analyze.log` + `flutter-test.log`；
  - `e2e-logs-<run_id>`：`.run/e2e/*.log`。
- 成功路径仅多一次 `tee` 写本地文件，不增加上传步骤。

## 兼容与升级

- 无 Alembic 迁移，直接升级即可；不需要改 `.env`。
- 网关 `POST /api/alerts/bulk-ack` 的 100 条上限保持不变，由客户端适配；
  Web 端仍按单次 100 条提交，不受影响。
- 设备列表接口的 `keyword` 语义未变；移动端仅改变查询方式与展示条数。

## 明确未覆盖（需要用户侧动作）

- 真机验收（弱网/切后台/权限拒绝/Keychain 与 Keystore）仍需在真实设备上执行，
  见 `docs/device-acceptance.md`。
- 生产 release 签名 secrets 未配置，CI 产物仍为 `-debug-signed`，不可对外分发。
- 定时备份/清理任务、日志聚合与 Prometheus 抓取需运维侧安装配置。
